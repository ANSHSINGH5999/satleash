No lnd node connected

The console shows live data from a real node: channels, the backup on your Nostr relays, relay health and security checks. Start the server with your node's details:

LND_CERT=<lnd dir>/tls.cert LND_MACAROON=<macaroon file> RELAYS=wss://relay-one.example,wss://relay-two.example npm run web

Or run the regtest playground, which builds a throwaway network with channels and connects this console to it:

npm run playground

Public relay test

Checks that a public relay accepts, serves and (optionally) deletes an event, without involving your backup. It publishes ONE encrypted dummy event signed by a throwaway key in its own namespace, reads it back, verifies the signature, then asks the relay to delete it. Your real backup, key and node data are never used.
